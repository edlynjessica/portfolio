## Run Locally

This portfolio uses React and Vite. Ensure Node.js and npm are installed.

1. Clone the repository:

   ```bash
   git clone https://github.com/edlynjessica/portfolio.git
   ```

2. Enter the project directory:

   ```bash
   cd portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

Use the local URL printed in the terminal to view the portfolio.
